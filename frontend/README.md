# ARTS - Frontend

Clean React + Vite single-page application for the Applicant Review & Team Selection System (ARTS) MVP.

## Tech Stack
- **Framework**: React 18
- **Build Tool**: Vite 6
- **Language**: JavaScript (ES Modules)

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Environment Variables
Copy `.env.example` to `.env` if custom API configurations are needed:
```bash
cp .env.example .env
```
Default `VITE_API_BASE_URL` points to `http://localhost:8000/api/v1`.

### 3. Run Development Server
```bash
npm run dev
```
The application will start at `http://localhost:5173`.
